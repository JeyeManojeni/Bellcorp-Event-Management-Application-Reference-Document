# EventFlow

EventFlow is a Next.js application for discovering, viewing, and managing event registrations. It features a modern UI, dynamic searching and filtering, user authentication, a personalized dashboard, and AI-powered event summaries.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

## Core Features

- **Event Discovery**: Browse events with dynamic searching and filtering.
- **Registration Management**: Register for events with capacity and authentication checks.
- **Personalized Dashboard**: View your upcoming and past registered events.
- **Automated Event Summaries**: Get concise, AI-generated summaries of event descriptions.
